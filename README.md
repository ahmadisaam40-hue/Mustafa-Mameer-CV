# Mustafa Sameer CV

A professional portfolio website for Mustafa Sameer - IT Professional & Tourism Manager.

## 🚀 Features

- Modern, responsive design with dark theme
- Interactive GSAP animations
- 3D hover effects on cards
- Smooth scroll animations
- LinkedIn integration
- CV download functionality

## 🛠️ Tech Stack

- **React** - Frontend framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **TailwindCSS** - Styling
- **GSAP** - Animations
- **Shadcn/UI** - UI Components

## 📦 Installation

```bash
npm install
```

## 🔧 Development

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 🚀 Deploy to GitHub Pages

```bash
npm run deploy
```
